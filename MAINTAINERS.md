## Responsibilities

- Review pull requests for correctness, security, tests, and documentation.
- Triage issues and keep the roadmap current.
- Prepare and publish releases from signed/checksummed artifacts.
- Respond to private security reports and coordinate disclosure.
- Enforce the Code of Conduct.

## Security contact

Do not email or DM maintainers with vulnerability details. Use the private
GitHub Security Advisory flow described in [`SECURITY.md`](SECURITY.md).
