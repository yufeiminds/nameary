# nameary Homebrew tap

Homebrew formula for [nameary](https://github.com/yufeiminds/nameary), the CLI
that checks a name across domains, package registries and handles.

## Install

```bash
brew install yufeiminds/tap/nameary
```

The formula is generated from the same GitHub release assets and
`checksums.txt` used by the other installers. It supports macOS and Linux on
`amd64` and `arm64`.

## Updating

This tap is updated automatically by the nameary release workflow. Do not edit
`Formula/nameary.rb` by hand.
