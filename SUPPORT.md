# Support

## Documentation

Start with:

- [`README.md`](README.md) — install, usage, targets, output modes.
- [`docs/sources.md`](docs/sources.md) — endpoints, limits and caveats.
- [`docs/release.md`](docs/release.md) — platforms, JSON schema, exit codes.
- [`docs/security-audit.md`](docs/security-audit.md) — security posture.

## Questions and bugs

Use GitHub Issues for reproducible bugs and concrete feature requests. Include:

- `nameary version`
- OS, architecture and terminal (for TUI issues)
- exact command, with secrets redacted
- expected vs. actual behavior
- relevant output, without tokens or private names

For usage questions, check existing issues first. There is no guaranteed
response time; this is a volunteer project.

## Security

**Do not open a public issue for a vulnerability.** Follow
[`SECURITY.md`](SECURITY.md).

## Supported versions

Security fixes target the latest `0.1.x` release. Older releases may not receive
patches.

## Commercial support

No commercial support is offered. If your organization depends on `nameary`,
consider contributing tests, documentation, or maintenance capacity.
